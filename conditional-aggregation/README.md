# SQL CONDITIONAL AGGREGATION

```
Use a CASE statement inside an aggregate function to perform calculations on a specific subset of data while keeping the rest of the query broad. This is often used to "pivot" data from rows into columns. 
```

#### start the docker compose before to run the queries:
```
docker compose up
```
